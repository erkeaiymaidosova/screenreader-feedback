# Обратная связь о действии для пользователей скринридеров

Исследовательский прототип для дипломной работы (категория «Научная статья»), Ala-Too International University, Бишкек. Это инструмент эксперимента, а не коммерческий продукт.

**Статус:** подготовка проекта (Этап 0). Самого прототипа пока нет.

## Цель

Исследовательский вопрос: как разные варианты обратной связи после действия влияют на то, понимают ли пользователи скринридеров (VoiceOver, TalkBack), удалось ли их действие, и насколько понятными и навязчивыми они эти варианты считают.

Прототип представляет собой мобильный веб-макет приложения рецептов. На нём проводится внутригрупповое исследование с 6–10 пользователями скринридеров.

| Код | Условие | Что происходит после нажатия |
| --- | --- | --- |
| C0 | Базовая линия | Только визуальное изменение, скринридеру ничего не передаётся |
| C1 | Речь | Статусное сообщение в области `role="status"` |
| C2 | Earcon | Короткий звук без речи |
| C3 | Earcon и речь | Сначала звук, затем сообщение как в C1 |
| C4 | Вибрация | Необязательное условие, по умолчанию выключено |

## Как запустить

Нужен только Python: он запускает простой локальный веб-сервер. Установка библиотек и сборка не требуются.

```bash
python3 -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`. Страница появится на Этапе 1.

## Этика и данные участников

- Участники обозначаются только кодами P1–P10. Имена и другие персональные данные не собираются.
- Журнал сессии хранится только в браузере устройства (`localStorage`) и сохраняется исследователем через экспорт.
- Прототип не использует бэкенд, аналитику, трекеры и внешние скрипты.
- Экспортированные данные и записи сессий не должны попадать в этот публичный репозиторий. Папки `data/` и `recordings/` исключены через `.gitignore`.
- Информированное согласие и этическое одобрение: *[заполнить после уточнения требований университета]*.

## Use of AI tools

При разработке прототипа используется **Claude Code** (модель Claude Opus 5.5, Anthropic) в VS Code: для написания и объяснения кода, технической документации и чек-листов.

- Решения о дизайне эксперимента принимает автор работы.
- Коммиты делает автор работы после проверки результата.
- Поведение скринридеров проверяется на реальных устройствах, а не принимается со слов AI.
- Текст диплома и статьи AI не пишет.
- Записи AI-чатов сохраняются и сдаются в соответствии с требованиями университета.
